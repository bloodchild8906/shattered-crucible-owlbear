INSTALLATION GUIDE

Install an extension

Follow the steps below to add a module to your Owlbear profile.

  1. Copy the manifest URL below.
  2. Open your Owlbear Rodeo profile and go to Extensions.
  3. Choose Add Extension, paste the URL, and approve it.
  4. Enable the extension in the room, then return here to confirm manually.

Installation confirmation is a local checklist, not a live check of your Owlbear account. Extensions cannot silently install other extensions.

All content uses Contract v1. Campaign data is not stored in Owlbear room metadata. This dashboard works as a standalone page or Owlbear popover.
